# Customer Analytics Data Pipeline and Business Intelligence Dashboard

## Project Overview

This project is an end-to-end customer analytics data pipeline built using Python, SQL, REST API integration, SQLite database storage, and Excel dashboard reporting.

The project extracts customer data from a REST API, creates order transaction data, cleans and transforms the datasets, stores them in a SQLite database, generates SQL-based summary reports, creates visual charts, and builds a dashboard-ready Excel file for business analysis.

## Objectives

- Extract customer data from a REST API
- Create and process order transaction data
- Clean and transform raw datasets using Python
- Store structured data in a SQLite database
- Perform SQL-based business analysis
- Generate summary reports for dashboarding
- Create an Excel-based BI dashboard
- Present business insights clearly
